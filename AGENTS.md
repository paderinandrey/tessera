# Working agreement for coding agents

Rules for automated agents working in this repository. They sit alongside
`CONTRIBUTING.md`, which applies to every contributor; where the two overlap,
`CONTRIBUTING.md` wins.

## Code Review Rules

- **Check every public API change for backward compatibility.** State plainly
  what breaks and for whom, before the change lands rather than after.
- **Do not run more than five review → fix iterations.**
- **After the fifth iteration, list the problems that remain and stop.** Stopping
  with an honest list is the required outcome, not a failure. Handing the
  remaining items to a human is what the limit is for.
